# MAVET — Panel de Administración

Sistema integral de gestión para el **Museo de Artes Visuales y del Espacio del Táchira**. Desarrollado en React + TypeScript + Tailwind CSS.

## Inicio Rápido

```bash
npm install
npm run dev
```
